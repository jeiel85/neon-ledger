# 네온 렛저: 언더그라운드 펀드 (Neon Ledger: Underground Fund)

> 2087년 가상도시 네오시티. 지하 헤지펀드 트레이더 'Ghost_7'이 되어 20개 가상 기업의 주가를 읽고, 베팅하고, 흔들어 1~2시간 안에 금융 제국을 세우는 사이버펑크 트레이딩 타이쿤 게임.

**▶ 라이브 데모: https://jeiel85.github.io/neon-ledger/**

설치·빌드 없이 브라우저에서 바로 실행되는 **단일 HTML 파일** 게임입니다. 외부 이미지, 폰트, 프레임워크, CDN을 쓰지 않습니다.

> **디스클레이머** — 이 게임은 완전한 허구이며 실제 금융 자문이 아니고 불법 행위를 조장하지 않습니다.
> 등장하는 기업, 인물, 기관(NCSC 등)은 모두 가상입니다. 정보 구매, 여론 캠페인, 방해공작, 로비 같은 게임 속 행동은 실제 절차가 아니라 숫자 스탯과 확률로만 표현한 추상적 게임 메커니즘입니다.

## 게임 목표

| 결과 | 조건 |
|---|---|
| 🏆 승리 | 가상 기업 **3곳의 지분 51%**를 확보해 적대적 인수 완료 (이후 샌드박스 모드로 계속 플레이 가능) |
| 🚨 게임오버 — 자산 몰수 | **NCSC Heat 100%** 도달 |
| 💸 게임오버 — 파산 | 순자산 ₵1,000 미만이면서 포지션·지분 없음 |

시작 자금은 ₵100,000입니다. 하루는 90틱(1틱 = 1초, 1x 속도 기준)입니다.

## 주요 기능

- **실시간 시장** — 섹터가 다른 20개 가상 기업. 변동성과 기준가 회귀를 반영한 랜덤워크 가격 시뮬레이션. 종목별 현재가, 등락률, 시가총액, 보유 지분 표시
- **캔들스틱 차트** — Canvas 2D로 그린 1초 단위 OHLC 캔들. MA5/MA20 이동평균, 포지션 진입가·강제청산가 라인, 마우스 오버 OHLC 표시
- **거래 데스크** — 시장가 Long / Short, 레버리지 1~5x 슬라이더, 증거금 퀵 버튼(10/25/50%/MAX), 50% 청산 / 전량 청산, 매 틱 강제청산 판정
- **다크웹** (전용 화폐 Dark Credits)
  - 인사이더 루머: 다음 날 특정 종목의 호재/악재 예고를 구매. 신뢰도 70~90%이며 빗나갈 수 있음. INTEL LEDGER에 적중 여부 기록
  - 루머 캠페인: 3단계 규모로 목표 종목을 끌어올리거나(PUMP) 끌어내림(DUMP). 발각되면 현금 일부가 동결되고 Heat 추가 상승
  - Firewall Breach: 타이밍 미니게임(`Space`로 정지). 성공하면 목표 종목이 일시 하락. 시가총액이 클수록 판정 구간이 좁아짐
- **Heat Control** — 정치자금(PF)을 써서 NCSC Heat를 낮추는 자원 교환. 75% / 90%에서 경고
- **M&A 레이어** — 시장 충격이 반영되는 지분 매집. 10% 구간을 처음 넘길 때마다 보너스 배당(시총 1%). 51%에서 적대적 인수가 완료되고 매일 고정 수익(시총 2.5%)과 정치자금이 들어옴
- **포트폴리오** — 순자산 추이 차트, 포지션·지분 요약, 플레이 통계
- **효과음** — 외부 오디오 파일 없이 Web Audio API 오실레이터로 실시간 합성(체결음, 상승/하락 비프, 현금 계수기, 속보 알림 등). 음소거 토글과 마스터 볼륨 지원
- **자동 저장** — 포트폴리오, 순자산, 일차, 기업 시세 이력까지 LocalStorage에 실시간 백업. 불러올 때 데이터 검증
- **속도 조절** — 일시정지 / 1x / 2x / 4x. 모달이 열리면 자동으로 일시정지
- **반응형 UI** — 네온 다크 테마, 모바일 레이아웃 대응

## 조작법

| 키 | 동작 |
|---|---|
| `1` ~ `6` | 탭 전환 (시장 / 거래 데스크 / 다크웹 / M&A / 포트폴리오 / 정보) |
| `P` | 일시정지 / 재개 |
| `Space` | Firewall Breach 미니게임 커서 정지 |

종목 목록에서 클릭하면 차트를 보고, 더블클릭하면 거래 데스크로 이동합니다.

## 로컬에서 실행

`index.html`을 브라우저로 바로 열면 됩니다. 로컬 서버로 실행하려면:

```bash
python -m http.server 8000
```

`http://localhost:8000`으로 접속합니다. 효과음은 브라우저 자동재생 정책 때문에 첫 클릭 이후부터 재생됩니다.

## 기술 스택

Vanilla JavaScript · Canvas 2D · Web Audio API · LocalStorage. 외부 의존성은 없습니다.
